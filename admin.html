Overview

GameNest.shop is a manual order counter for Fortnite V-Bucks and Crew. Customers fill a ticket on the site, then complete the order with an admin in Discord.

—Average rating
—Total ratings

Live site: gamenest.shop

Order Flow

  • Pick a pack or Crew length
  • Add Fortnite/Epic username
  • Copy the generated ticket
  • Join the GameNest Discord
  • Create a ticket in the server
  • Paste the ticket to the admin
  • Pay the admin directly
